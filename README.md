# Polo Umpire

Offline-first PWA para árbitros de polo basada en el USPA Rulebook.

## Modos de consulta

- **Jugada**: analiza una acción concreta de juego, hace preguntas de contexto y devuelve las reglas aplicables.
- **Situación reglamentaria**: resuelve cuestiones que no dependen de una jugada puntual, como substitutes/alternates, elegibilidad, handicap, equipamiento y procedimientos.

## Principios

- Core reglamentario disponible sin conexión.
- Rulebook versionado y precargado.
- Respuestas trazables a Rule / subsection / Interpretation / Example.
- IA opcional para entender lenguaje natural; el Rulebook sigue siendo la fuente de verdad.
- Actualizador preparado para detectar nuevas versiones oficiales.
